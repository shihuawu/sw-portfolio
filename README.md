# Shihua Wu Portfolio

An interactive portfolio for Shihua Wu, an AI-Native Operator. The site uses a basketball shot chart to unlock three real builds. An assist mode removes the timing requirement while preserving the interaction.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
```

## Deployment

Import the repository into Vercel. Next.js is detected automatically; no custom build settings are required.
